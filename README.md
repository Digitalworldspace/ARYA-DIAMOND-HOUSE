## Add your real certificates

Place your genuine certificate JPG/PNG files inside:

```text
images/certificates/
```

Then replace the certificate placeholder in `index.html` with an actual `<img>` tag for your certificate.

## GitHub Pages

1. Create a GitHub repository.
2. Upload the complete folder structure.
3. Go to Settings → Pages.
4. Select Deploy from a branch.
5. Select `main` and `/root`.
6. Save.

The website is static HTML/CSS/JavaScript and does not require a backend.
